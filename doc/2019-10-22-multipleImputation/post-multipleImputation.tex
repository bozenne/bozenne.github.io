Just to have an example to work with. Generative model:
\begin{lstlisting}[language=r,numbers=none]
mSim <- lvm(Y~group+season+bmi+gender+age)
categorical(mSim, labels = c("winter","summer")) <- ~season
categorical(mSim, labels = c("SAD","HC")) <- ~group
categorical(mSim, labels = c("Male","Female")) <- ~gender

\subsection{Step 2: Reflect upon the missing data and correlation patterns}
\label{sec:orge59a0af}

It is often useful to consider the missing data patterns next to the
association between variables. Ideally the association pattern should
be based on prior knowledge as the empirical one (i.e. based on the
observed data) may be difficult to estimate reliably in presence of
missing data. To keep things concrete, let's use a rough approximation
(pearson correlation also for categorical variables) of the
correlation structure:
\begin{lstlisting}[language=r,numbers=none]
dtNum.data <- as.data.frame(lapply(dt.data,as.numeric))
cor.data <- cor(dtNum.data, use = "pairwise")
cor.data[setdiff(colnames(md.data),""),
         setdiff(colnames(md.data),"")]
\end{lstlisting}

\phantomsection
\label{}
\begin{verbatim}
             group      season      gender           Y         bmi         age
group   1.00000000 -0.08242959 -0.04222003  0.11147368 -0.09679738  0.09304925
season -0.08242959  1.00000000 -0.09090909  0.09219243  0.06508765  0.07620663
gender -0.04222003 -0.09090909  1.00000000 -0.12831302  0.04329831 -0.17662044
Y       0.11147368  0.09219243 -0.12831302  1.00000000  0.32446590  0.98452932
bmi    -0.09679738  0.06508765  0.04329831  0.32446590  1.00000000  0.16195300
age     0.09304925  0.07620663 -0.17662044  0.98452932  0.16195300  1.00000000
\end{verbatim}


\textbf{Intuition}: A complete case analysis where \texttt{Y} is regressed against
\texttt{group}, adjusting for \texttt{season}, \texttt{gender}, \texttt{bmi}, \texttt{age} would discard
information from all the 20 subjects with missing values.
\begin{itemize}
\item Complete case would discard valuable information for the 10 subjects
where \texttt{Y} is known but \texttt{age}. Indeed, \texttt{age} being very correlated
with \texttt{Y}, those subjects are not really missing data. Multiple
imputation can avoid discarding such valuable information, leading
to superior statistical power and possibly less bias.
\item the 10 subjects missing \texttt{bmi}, \texttt{age}, and \texttt{Y} carry little
information as \texttt{group}, \texttt{season}, and \texttt{gender} do not seem to be
particularly useful to guess the missing values. In that case
multiple imputation would essentially impute the group mean for
\texttt{bmi}, \texttt{age}, and \texttt{Y} leading to similar results as complete case
analysis.
\end{itemize}

\clearpage

\textbf{Multiple imputation (MI) vs. complete case (CC)} \citep{vanbuuren2018}:
  "Suppose that the complete-data model is a regression with outcome
  \(Y\) and predictors \(X\). If the missing data occur in \(Y\) only,
  complete-case analysis and multiple imputation are equivalent [\ldots{}]
  Multiple imputation gains an advantage over complete-case analysis
  if additional predictors for \(Y\) are available that are not part
  of \(X\). The efficiency of complete-case analysis declines if \(X\)
  contains missing values. [\ldots{}] there are two special cases where
  listwise deletation outperforms multiple imputation [\ldots{}]
\begin{itemize}
\item the probability to be missing does not depend on Y
\item the complete data model is logistic regression [\ldots{}] the
probability to be missing depends only on Y and not on X"
\end{itemize}

\subsection{Step 3: Define imputation model}

\begin{lstlisting}[language=r,numbers=none]
all.variables <- setdiff(colnames(md.data),"")
n.variables <- length(all.variables)
Mlink <- matrix(0, n.variables, n.variables,
                dimnames = list(all.variables,all.variables))
Mlink["Y", which(colnames(Mlink)!="Y")] <- 1
Mlink["age", which(colnames(Mlink)!="age")] <- 1
Mlink["bmi", which(colnames(Mlink)!="bmi")] <- 1
Mlink

\section{Special case: imputation using a specific law and no covariate}
\label{sec:orgae21c12}
Mice can be adapted in order, for instance, to sample from a uniform
distribution or a truncated normal distribution. First define a
function able to generate data like:
\begin{lstlisting}[language=r,numbers=none]
mice.impute.SI_unif <- function(y, ry, ...){ ## uniform xglaw
    n.NA <- sum(ry==FALSE)
    sample <- runif(n.NA, min = 0, max = 1)
    return(cbind(sample))
}
\end{lstlisting}

or

\begin{lstlisting}[language=r,numbers=none]
mice.impute.SI_tnorm <- function(y, ry, ...){ ## truncated normal law
    require(truncnorm)
    n.NA <- sum(ry==FALSE)
    sample <- rtruncnorm(n.NA, a = 0, b = 1, mean = 1, sd = 0.1)
    return(cbind(sample))
}
\end{lstlisting}
Then prepare the matrix indicating which variable should be used
during the imputation:
\begin{lstlisting}[language=r,numbers=none]
impute.var <- c("bmi","group")
Mlink2 <- matrix(0, 
                 nrow = length(impute.var), 
                 ncol = length(impute.var), 
                 dimnames = list(impute.var,impute.var))
Mlink2["bmi","group"] <- 1
Mlink2
\end{lstlisting}

\section{Reporting guideline}
\label{sec:orgc71f668}
From \url{https://stefvanbuuren.name/Winnipeg/Lectures/Winnipeg.pdf}:
\begin{itemize}
\item Amount of missing data
\item Reasons for missingness
\item Differences between complete and incomplete data
\item Method used to account for missing data
\item Software
\item Number of imputed datasets
\item Imputation model
\item Derived variables
\item Diagnostics
\item Pooling
\item Listwise deletion
\item Sensitivity analysis
\end{itemize}
